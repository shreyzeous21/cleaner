# Cleaner

A Tauri + React + TypeScript desktop app that scans your Mac for safe-to-remove
junk (caches, logs, npm cache), finds large files and duplicates, cleans old
files, uninstalls apps with their leftovers, manages startup items, and empties
the Trash — nothing is permanently deleted without your explicit confirmation.

## Features

**Dashboard**
- Automatic junk scan on startup (stat cards, bar chart, donut chart)
- Reclaimable-space hero card
- Clickable categories that expand into per-file details (Scan Details)
- One-click cleaning to the Trash

**Smart Scan**
- One button that totals junk, large files, duplicates, and old files

**Storage**
- Disk usage overview with a fullness progress bar and detailed stats

**Large Files**
- Finds files over 50 MB in your home folder, checkbox-select, move to Trash

**Duplicates**
- Detects identical files (size + content hash), trash selected copies

**Browsers**
- Safari / Chrome / Firefox cache scanner, empty selected caches

**Old Files**
- Files in your home folder not modified in 30/90/180/365+ days

**Startup Apps**
- Lists login items / LaunchAgents, disable them (plist moved to Trash)

**Apps**
- Lists installed `.app` bundles with sizes, shows related leftover data
  (Application Support, Caches, Preferences, Logs, …), uninstalls the app plus
  selected leftovers

**Tools**
- Quick rescan
- Auto-clean schedule (hourly/daily/weekly — safe categories only)
- Empty Trash (macOS: empties via Finder; Windows: clears Recycle Bin; Linux: clears Trash)
- Cleanup history (what was moved to Trash and when)

**General**
- Dark mode toggle
- shadcn sidebar layout with a fixed header and scrollable content
- Sticky action bars on list views
- Custom app icon (gradient sparkle, generated via `tauri icon`)
- All deletion is **Trash-based** — files go to the Trash first, never erased

## How it works

1. `scan` — Rust walks the junk categories and returns sizes/file counts.
2. You pick categories in the UI (checkboxes); expand one to see its files.
3. `clean` — Rust empties each selected category into the **Trash**; skipped
   permission-protected items are logged, not shown as errors.
4. `disk_usage` — free/total/used bytes for the root volume.
5. `large_files` / `duplicates` / `browser_entries` / `old_files` — scanner
   commands with the same checkbox-to-Trash flow.
6. `list_apps` → `app_leftovers` → `uninstall_app` — the app uninstaller flow.
7. `empty_trash` — macOS empties via Finder (needs Automation permission),
   Windows clears the Recycle Bin, Linux clears the Trash.
8. Cleanup history records every clean/uninstall in
   `~/Library/Application Support/cleaner/history.json`.

## Commands

```bash
npm run tauri dev     # Run the desktop app in dev mode
npm run tauri build   # Build a production .app (required to see the app icon)
npm run build         # Type-check and build the frontend
cd src-tauri && cargo check   # Check the Rust side
```

## Notes on macOS permissions

- First time you use **Empty Trash**, macOS asks to let Cleaner control Finder —
  allow it. If blocked, enable it in **System Settings → Privacy & Security →
  Automation → Cleaner → Finder**.
- Reading `~/.Trash` directly is blocked by macOS, so the freed-space number for
  "Empty Trash" can show `0 B` even though the Trash was emptied (Finder
  handles the actual deletion).
